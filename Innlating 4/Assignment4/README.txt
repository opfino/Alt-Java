Assignment4 - Ricochet Robots console game

How to compile:
    javac src/*.java

How to run:
    java -cp src Game

Controls:
    Choose a robot by typing AA, BB, or CC.
    Move with w/a/s/d or north/south/west/east.
    Type q when asked for a robot to quit.

Notes:
    Coordinates in the code are 0-based: x is the column and y is the row.
